# Configuration reference

[Project README](../README.md) · [Documentation index](README.md)

Environment variables for Django, databases, encryption, email, and media.

## Environment configuration

`app/settings.py` reads the process environment. Database configuration follows this precedence: `DATABASE_URL` when provided; SQLite when `DATABASE_ENGINE=sqlite`; otherwise, PostgreSQL using the `POSTGRES_*` variables.

### Application and database

| Variable | Purpose |
| --- | --- |
| `DJANGO_DEBUG` | Enables development mode. A deployed environment must set it to `False`. |
| `DJANGO_SECRET_KEY` | Signs sessions and tokens. Required when debug mode is disabled. |
| `DJANGO_ALLOWED_HOSTS` | Accepted hosts, separated by commas. |
| `PUBLIC_SITE_URL` | HTTPS origin used for canonical URLs, the sitemap, and metadata. Validation requires an origin with no additional path. |
| `DJANGO_CSRF_TRUSTED_ORIGINS` | Trusted origins for forms; separate multiple origins with commas. |
| `DJANGO_SECURE_SSL_REDIRECT` | Controls HTTPS redirects. The local demo sets it to `False`. |
| `DJANGO_SECURE_HSTS_SECONDS` | HSTS policy duration. |
| `DATABASE_URL` | Full PostgreSQL connection URL; supports options such as `sslmode=require`. |
| `DATABASE_ENGINE` | `sqlite` for the demo or `postgresql` for PostgreSQL. |
| `SQLITE_NAME` | SQLite database path; the example uses `demo.sqlite3`. |
| `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` | Database, username, and password when `DATABASE_URL` is empty. There is no hardcoded password. |
| `POSTGRES_HOST`, `POSTGRES_PORT` | PostgreSQL host and port. |
| `POSTGRES_CONN_MAX_AGE` | Connection reuse duration, in seconds. |

In the demo example, `PUBLIC_SITE_URL=https://localhost` configures metadata; the development server is accessed over HTTP as shown in the commands above.

### Data protection and authentication

| Variable | Purpose |
| --- | --- |
| `FIELD_ENCRYPTION_KEYS` | Comma-separated, versioned keys in the format `v1:<32-byte-base64url-key>`. |
| `FIELD_ENCRYPTION_ACTIVE_KEY` | Version used for new writes. It must exist in `FIELD_ENCRYPTION_KEYS`. |
| `FIELD_HASH_KEY` | An independent 32-byte key for HMAC indexes used in comparisons and lookups. |
| `AUTH_LOCKOUT_THRESHOLD` | Failures before temporary lockout; defaults to 5. |
| `AUTH_LOCKOUT_BASE_SECONDS` | Initial lockout duration; defaults to 30 seconds. |
| `AUTH_LOCKOUT_MAX_SECONDS` | Maximum progressive lockout duration; defaults to 900 seconds. |
| `AUTH_LOCKOUT_RESET_SECONDS` | Expiration interval for failed-attempt history; defaults to 3,600 seconds. |

### Email, media, and observability

| Variable | Purpose |
| --- | --- |
| `EMAIL_BACKEND` | Delivery implementation: local console, in-memory backend for tests, or SMTP in production. |
| `EMAIL_DELIVERY_ENABLED` | Enables or disables verification email delivery. |
| `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD` | SMTP server access when that backend is active. |
| `EMAIL_USE_TLS`, `EMAIL_TIMEOUT`, `DEFAULT_FROM_EMAIL` | TLS, timeout, and sender address. |
| `RESEND_API_KEY` | Worker secret passed to the container as the SMTP password. |
| `MEDIA_STORAGE_ENDPOINT` | Empty for local files; `http://media.internal` for the Worker's R2 adapter. |
| `CORS_ALLOWED_ORIGINS` | Origins explicitly authorized to read public pages; empty by default, with no wildcard support. |
| `GOOGLE_SITE_VERIFICATION` | Optional value for the website verification meta tag. |
| `DJANGO_LOG_LEVEL` | Application logging level. |

The `.env` generated by the script is for development only. Production secrets are configured with the provider. The encryption rotation command and precautions for keeping the HMAC key stable are documented in [SECURITY_DEPLOYMENT.md](../SECURITY_DEPLOYMENT.md).
